# Project Catalog JSON

The project catalog has been exported to [`project.json`](./project.json).

Each project entry follows the portfolio project schema with these fields:

- `id`
- `title`
- `description`
- `status`
- `repo`
- `backendRepo` (optional)
- `liveUrl` (optional)
- `techStack`
- `features`
- `responsibilities`
- `impact`
- `category`
- `tags`
- `domain`
- `complexity`

Allowed project categories are maintained in `app/types/index.ts` under `ProjectCategory`.
