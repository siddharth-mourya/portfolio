# Siddharth Mourya Portfolio

A professional portfolio website built with Next.js, TypeScript, Tailwind CSS, and MDX for blog content.

## Features

- Modern App Router structure
- MDX-powered blog system
- Projects and project detail pages
- Skills, experience, dashboard, and resume sections
- SEO metadata, sitemap, and robots.txt
- Dark/light theme toggle with `next-themes`
- Responsive, accessible, and performance-focused design

## Available Scripts

In the project directory, run:

### `npm install`

Install dependencies.

### `npm run dev`

Start the development server at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Create an optimized production build.

### `npm start`

Start the production server after building.

### `npm run lint`

Run Next.js lint checks.

## Deployment

Deploy this portfolio to Vercel or any platform that supports Next.js.

## Project Structure

- `app/` - Next.js App Router pages and layouts
- `components/` - Reusable UI components and sections
- `content/blog/` - MDX blog articles
- `data/` - Structured project, skill, experience, and blog metadata
- `public/` - Static assets and platform files
- `types/` - TypeScript data definitions

## Notes

This site is designed for senior frontend engineering and product leadership, with polished storytelling, reusable design system components, and a strong technical portfolio presentation.
